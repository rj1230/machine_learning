## Overview

This repository contains a set of **end-to-end machine learning projects** covering classification, regression, financial time-series analysis, and exploratory data analysis (EDA).

Each project follows a complete workflow — data cleaning, exploratory analysis, feature engineering, model training, evaluation, and interpretation — demonstrating practical application of core ML concepts on real-world datasets.

---

## Projects

| Project | Domain | Description |
|---|---|---|
| **Spam Classifier** | NLP / Text Classification | Detects spam messages using text preprocessing and classification models. |
| **TrendClassifier** | Financial Time Series | Classifies financial market trends using time-series feature engineering and supervised learning. |
| **Credit Card Analytics** | Financial / Risk Modeling | Analyzes credit card transaction data and builds predictive models for risk-related outcomes. |
| **Customer Churn Prediction** | Classification | Predicts customer churn using behavioral and demographic features to support retention strategies. |
| **NYC Airbnb Analysis** | Regression / EDA | Performs exploratory analysis of Airbnb listings and builds predictive models for pricing and demand. |

## Key Features

### Data Preprocessing & EDA

- Systematic data cleaning, missing-value handling, and outlier detection
- Exploratory data analysis with statistical summaries and visualizations
- Feature engineering and encoding for categorical and numerical variables

### Model Development

- Supervised learning workflows for classification and regression tasks
- Model training, hyperparameter tuning, and cross-validation
- Performance evaluation using appropriate metrics per task (accuracy, precision, recall, F1, RMSE, R²)

### Reproducible Workflows

- Modular, notebook-driven project structure
- Consistent use of `requirements.txt` for dependency management
- Clear separation of data, notebooks, and source code per project

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/machine_learning.git
   cd machine_learning
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
