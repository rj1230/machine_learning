# Machine Learning Projects

A collection of machine learning projects covering classification,
regression, financial time-series analysis, and exploratory data analysis.

## Projects

- **Spam Classifier** — Spam detection and text classification.
- **TrendClassifier** — Financial market trend classification.
- **Credit Card** — Credit card data analysis and modeling.
- **Customer Churn** — Customer churn prediction.
- **NYC Airbnb** — Airbnb listing analysis and predictive modeling.

## Technologies

- Python
- pandas
- NumPy
- scikit-learn
- Matplotlib / Seaborn

## Setup

Create and activate a virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

## Note

Dataset availability, model artifacts, and execution instructions may vary
by project. See individual project directories for details.
